# 04 — DESIGN SYSTEM (follow literally)

## Concept: "Campus Noticeboard"
UniSphere should feel like a lively university noticeboard crossed with Pakistani truck-art colour: flat, saturated colour blocks, thick ink outlines, hard offset shadows, stickers/tags, confident type. It should look hand-designed for a campus, not generated by a SaaS template.

## Palette (flat colours only — NO gradients anywhere)
| Token | Hex | Use |
|---|---|---|
| `--paper` | `#EEF2EC` | Page background (cool pale green-grey, not cream) |
| `--surface` | `#FFFFFF` | Panels, forms |
| `--ink` | `#16202B` | Text, borders, hard shadows |
| `--emerald` | `#0B7A55` | Primary actions, "approved", brand |
| `--marigold` | `#FFB703` | Highlights, seats-left, key stickers |
| `--rose` | `#E63462` | Alerts, reject, over budget, notifications dot |
| `--sky` | `#3FA7D6` | Info, in-progress, links |
| `--lilac-ink` | *(not used)* | — no purple at all |
| `--mist` | `#D9E2DA` | Dividers, disabled, secondary fills |

Status colours: Draft = mist + ink text; Pending = marigold; Approved = emerald; Rejected = rose; Cancelled = ink-outline on paper with strikethrough title; Upcoming = sky; Ongoing = emerald with pulsing dot; Completed = mist.
Text on emerald/rose/ink = white. Text on marigold/sky/mist = ink. Maintain WCAG AA contrast.

Tailwind: define these in `tailwind.config.ts` `theme.extend.colors` and as CSS variables. Never use default Tailwind purple/indigo/violet/blue gradients.

## Typography
- Display + headings: **Bricolage Grotesque** (700/800), tight tracking (-0.02em)
- Body + UI: **Figtree** (400/500/600)
- Load via `next/font/google`. No Inter, no Poppins, no Space Grotesk, no monospace labels.
- Scale: 14 / 16 / 18 / 22 / 30 / 44 / 72. Body 16px, line-height 1.55. Max line length ~65ch.
- Headings are sentence case. No ALL-CAPS eyebrow labels above headings. No gradient text. Don't colour a single word in a headline.

## Shape & surface
- Borders: `2px solid var(--ink)` on cards, inputs, buttons.
- Shadows: **hard offset only** e.g. `4px 4px 0 var(--ink)`. Hover on interactive: shadow shrinks to `2px 2px 0` and element translates `2px,2px` (feels pressed). No blurred soft shadows, no glassmorphism, no glow.
- Radius varies with role (don't use one radius everywhere): buttons 10px, inputs 8px, event cards 18px, tags/stickers fully round, modals 20px, avatars circle.
- Layout is not a uniform card grid. Mix: one large "featured" event block (marigold or emerald full-bleed) + a tighter list rows for the rest; asymmetrical columns on landing; dense table/list rows on admin pages.
- Icons: `lucide-react`, stroke 2px, matching ink colour. No emoji as icons.
- Avatars for societies without a logo: coloured circle (rotate through palette) with first letter, 2px ink border.

## Landing page layout
```
[logo wordmark]                              [Browse events] [Log in] [Sign up]
------------------------------------------------------------------------------
 Big headline (72px, left aligned, 2–3 lines):
   "Every society. Every event. One noticeboard."
 Sub (18px): one sentence on what students / organizers / admin get.
 [Join UniSphere]  [See what's on]                     [ tilted sticker stack:
                                                         3 real upcoming events
                                                         as paper tickets with
                                                         date stub, slightly
                                                         rotated -2°/1°/-1° ]
------------------------------------------------------------------------------
 "Coming up" — real events from DB (3–6): first is a wide featured ticket, the rest compact rows.
------------------------------------------------------------------------------
 Three role panels in an asymmetric 5/4/3 column split (colour-blocked emerald / marigold / ink):
   Students find it · Organizers run it · The university sees it  (short, concrete copy)
------------------------------------------------------------------------------
 Footer: small, plain.
```
Copy: plain, specific, no buzzwords ("seamless", "empower", "revolutionize", "all-in-one" are banned).

## Dashboards
- App shell: left rail (ink background, paper text, active item = marigold block), top bar with page title + notification bell (rose dot with count) + user chip.
- President home: society header band (emerald), stat tiles with different sizes, "Needs your attention" list (pending requests, rejected events, overdue tasks).
- Student home: "Your next event", "Invitations", "My tasks" ordered by due date.
- Admin home: 3 counters + pending proposals table with budget column and Review buttons.
- Kanban: columns with different header colours (mist / sky / emerald); task cards with priority tag (High = rose, Medium = marigold, Low = mist), due date chip turning rose when overdue.

## Motion (framer-motion) — purposeful, not scattered
1. **One orchestrated landing moment**: on first load, headline words slide up in a quick stagger (0.5s total), the ticket stack drops in and settles with a small rotation spring. Plays once.
2. **Responds to action only** elsewhere:
   - Buttons: press effect (translate + shadow shrink, 120ms).
   - Register/Join: button morphs to confirmed state; seat counter animates the number change (roll up/down, 300ms) with a brief marigold flash.
   - New notification: toast slides in from top-right with spring; bell wiggles once.
   - Kanban: layout animation (`layout` prop) when a card moves column.
   - Modals: scale 0.96 -> 1 + fade, 180ms. Route changes: simple 150ms fade only.
   - Progress bars fill on mount (once, 600ms ease-out). Count-up on admin stats once on mount.
3. Do NOT animate every card/section with fade-up on scroll. Do NOT use floating blobs, parallax, particles, or looping background animations.
4. Respect `prefers-reduced-motion` (disable stagger/spring, keep instant state changes).

## Copy & states
- Buttons name the action: "Submit for approval", "Request to join", "Save society". Success toast reuses the same verb: "Submitted for approval".
- Empty states say what to do: "No events yet. Create your first event and send it for approval."
- Errors say what failed + fix: "This event is full. Check back if someone cancels."
- Loading: skeletons shaped like the content (not spinners everywhere).
- Dates always shown in PKT with "PKT" suffix. Money shown as `Rs 12,500`.

## Accessibility & responsive
- Mobile first; sidebar becomes a bottom bar/drawer under 768px; tables collapse to stacked rows.
- Visible focus ring: `3px` marigold outline offset 2px.
- Labels on all inputs, `aria-live` for toasts and seat count.

## Anti-patterns (audit every page against this list)
- [ ] Any gradient, glow, blur/glass, or blob
- [ ] Purple / indigo / violet anywhere
- [ ] Same radius + same soft shadow on every card
- [ ] Grid of identical cards as the main layout
- [ ] Gradient or single-word-coloured headlines
- [ ] ALL-CAPS tracked eyebrow labels, "01 / 02 / 03" markers on non-sequential content
- [ ] Emoji used as icons; stock "rocket/sparkles" imagery
- [ ] Fade-up on every section; looping animations
- [ ] Generic copy ("Welcome to the future of...")
- [ ] Inter / Poppins font
